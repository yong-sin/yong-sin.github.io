## Simplest upload to your existing yong-sin.github.io repository
1. Download the **complete site ZIP**, unzip it locally.
2. Open your existing GitHub repository on branch `main`.
3. In the extracted folder, select **all contents** (not the outer enclosing folder and not the ZIP itself): `index.html`, `assets`, `projects`, `creative`, and `README.md`.
4. GitHub: **Add file → Upload files**. Drag those selected items into GitHub. Preserve folder paths.
5. Commit to `main`. Confirm Settings → Pages → Deploy from branch → `main`, `/(root)`.
6. Check `https://yong-sin.github.io/`. Then open each project card and play its media.
7. The existing old root `eng1013.html` is not used by the new homepage. You can remove it after checking the new site.

If browser folder upload proves awkward, use GitHub Desktop to commit the unzipped folder contents at repo root. Every asset in this package is under GitHub's standard per-file 25 MiB browser limit.
