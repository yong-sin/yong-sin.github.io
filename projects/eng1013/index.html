Traffic Light Control System

A working traffic-light control prototype programmed in Python using Pymata4 and Arduino. The final implementation combines normal timed operation, day/night detection, temperature sensing and pedestrian push-button input.

Final implementation

We built a working Python/Pymata4 and Arduino traffic light controller. The finished system included:

  • Normal time-based traffic-light execution.
  • Day/night detection.
  • Temperature sensing.
  • Pedestrian push-button input.

The team's Milestone 1 design also documents a six-stage signal sequence and ultrasonic vehicle-distance measurements.

My contribution

  • Implemented the main Python/Pymata4 traffic-light controller and timed stage sequence.
  • Worked on vehicle-distance sensing, day/night detection, temperature sensing and pedestrian push-button input.
  • Integrated and tested the working system with Arduino hardware.
  • The seven-segment display and emergency supply subsystem were developed by teammates.

Engineering approach

The project was divided into control, input, service and output subsystems. Python and Pymata4 communicated with Arduino hardware to operate the traffic-light prototype. The control sequence coordinated timed signal changes, with the final system also incorporating day/night detection, temperature sensing and pedestrian input. The video shows the team's working electronics demonstration.
